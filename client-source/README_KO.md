# AKFES Windows + Web 운영 클라이언트 v25 소스

이 패키지는 서버 코드·데이터베이스·Redis·운영 비밀값을 포함하지 않습니다. 클라이언트는 다음 주소에 고정됩니다.

- API/Auth: `https://api.akfes.pe.kr`
- WebSocket: `wss://api.akfes.pe.kr`

`scripts/build-vultr-production-client.ps1`로 운영 실행 파일과 바로 설치할 수 있는 Windows 설치 프로그램을 빌드합니다. Arduino IDE 없이도 펌웨어를 설치할 수 있도록 고정 버전 Arduino CLI/AVR 코어를 Setup 파일에 포함하며, 긴 Windows 경로에서도 동작하도록 내부 도구 묶음은 tar 형식을 사용합니다. `local-test-provisioning` 기능은 운영 빌드에 포함되지 않으므로 클라이언트가 서버 비밀값을 생성하거나 로컬 테스트 서버를 프로비저닝할 수 없습니다.

최초 장치 승인 시 운영 서버는 아직 승인된 장치가 없는 원래 등록 장치에만 장치별 Arduino 키를 전달합니다. Windows 앱은 이 키로 선택한 Arduino 펌웨어를 자동 생성·업로드한 뒤 서버 challenge를 검증합니다. 서버 마스터 키는 클라이언트로 전달되지 않습니다.

## 웹 장치

- `client/src/web-crypto.ts`는 Tauri가 없는 브라우저에서 Ed25519/X25519, PreKey, E2EE v4 Ratchet, Safety Number와 암호화 파일 기능을 제공합니다.
- 웹 장치 상태는 계정 비밀번호 기반 PBKDF2/AES-GCM으로 암호화되어 IndexedDB에 저장됩니다.
- 접근 토큰은 메모리에만 유지됩니다.
- 웹 장치 승인과 폐기는 Windows 앱 + Arduino에서 수행합니다.
- Vultr에서 직접 제공하는 웹판은 `AKFES-Vultr-Server-v10/web`에 포함되며 Windows 앱과 같은 React 화면과 E2EE 흐름을 사용합니다.

## 화면 캡처·비밀 내용 보호

- Windows 설치 앱은 전체 창에 운영체제의 `WDA_EXCLUDEFROMCAPTURE` 보호를 적용합니다. 지원되는 Windows 캡처·화면 녹화·화면 공유 경로에서는 앱 영역이 제외됩니다.
- 비밀 메시지와 비밀 첨부는 복사, 잘라내기, 드래그, 컨텍스트 메뉴와 인쇄를 차단합니다.
- 비밀 내용이 열린 상태에서 다른 창이나 탭으로 전환하거나 페이지가 숨겨지면 복호화 키와 메모리 미리보기를 즉시 폐기합니다. 다시 보려면 Arduino PIN 승인이 필요합니다.
- 웹 브라우저는 다른 프로그램이나 운영체제의 캡처를 확실히 차단할 권한이 없습니다. 웹판은 화면공유 API 비활성화, 자동 잠금, 복사·인쇄 제한을 적용하지만 외부 카메라, 관리자 권한 캡처, 하드웨어 캡처까지 막는다고 보장하지 않습니다.

## v25 복구·동기화·Arduino PIN

### 키패드 연결과 키바인딩

Windows 앱의 **Arduino 키패드 추가 인증 → 키패드 PIN·키바인딩 변경**에서 4×3 또는 4×4 키패드를 선택할 수 있습니다. 기본 4×3 연결은 다음과 같습니다.

```text
키패드 R1 R2 R3 R4 -> Arduino D2 D3 D4 D5
키패드 C1 C2 C3    -> Arduino D6 D7 D8
기본 키 배치       -> 1 2 3 / 4 5 6 / 7 8 9 / * 0 #
*                   -> 입력 전체 지우기
#                   -> PIN 확인
```

4×4는 C4에 D9를 추가합니다. 앱에서 행·열 GPIO, 물리 키 배치, 지우기 키와 확인 키를 바꿀 수 있습니다. D0·D1은 USB 직렬 통신용이므로 키패드에 사용할 수 없습니다.

새 PIN은 앱이 아니라 키패드에서 두 번 입력하고 각 입력 뒤 확인 키를 누릅니다. 평상시 장치 승인·폐기도 키패드에서 처리하며 PIN 평문은 USB 직렬 통신이나 서버 요청에 포함되지 않습니다.

기존 앱 방식 PIN 펌웨어를 이미 사용 중이면 **기존 펌웨어를 키패드용으로 전환**을 먼저 누릅니다. 앱은 이 PC에 보관된 기존 장치 결속만 재사용해 서버 PIN 키를 바꾸지 않고 새 프로토콜을 올립니다. 업로드 뒤 키패드에서 기존 PIN과 확인 키를 눌러 전환을 검증합니다.

- 가입 도중 앱이나 브라우저를 닫은 계정은 서버 v10에서 같은 아이디와 비밀번호로 로그인하거나 가입을 다시 진행해 복구할 수 있습니다.
- 새 메시지는 상대방의 승인 장치뿐 아니라 발신자의 다른 승인 장치에도 장치별 독립 암호문으로 전송됩니다.
- 다른 장치 동기화는 서버 v10과 클라이언트 v25 적용 뒤 새로 보낸 메시지부터 시작됩니다.
- Arduino PIN은 6~12자리 숫자이며 펌웨어에 저장되지 않습니다. 서버에는 키패드가 만든 장치 결속 파생 검증 키만 감싸서 저장됩니다.
- 브라우저에서는 채팅을 사용할 수 있지만 Arduino USB 검색과 펌웨어 업로드는 Windows 앱에서 수행해야 합니다.
